# Utility Billing & Management System

A clean console-based **Electricity Bill Generation System** refactored in **Python 3**. This system automates consumer portfolio records and handles tier-structured tariff rate computational tracking.

## Core Features
- **Profile Registration:** Unique 6-digit identification tags mapped with individual profile configurations.
- **Dynamic Tier Calculations:** Automated conditional loops to process separate pricing tiers for both Domestic and Commercial clients.
- **Persistent Flat-File Memory:** Real-time serialization into flat database systems (`utility_consumers.txt`).
- **Billing Auditing Checkpoint:** Computes net kilowatt-hour consumption metrics instantly upon user metrics input.

## Execution Matrix
Execute using the standard python shell runtime:
```bash
python main.py
```
